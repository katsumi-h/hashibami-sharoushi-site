# はしばみ社会保険労務士事務所（練習用サイト）

**本サイトは練習用に作成した架空の事務所サイトです。** 掲載している事務所名・代表者名・住所・電話番号はすべてダミーであり、実在の事務所とは関係ありません。

## 概要
- ホームページ制作の工程練習として作成
- 参考サイト（構成）：[sanjo-law.com](https://sanjo-law.com/)（ひめさゆり法律事務所）
- 参考サイト（配色）：[m-staff.com](https://m-staff.com/)、[classico-os.com](https://classico-os.com/)
- 文章・配色・画像はすべてオリジナル（参考サイトのコピー・画像・CSSは使用していません）

## 制作の流れ
`docs/` フォルダに、企画〜設計の各ステップの成果物を残しています。実案件の要件定義フェーズでもそのまま使える形式です。

1. [docs/01_案件概要.md](docs/01_案件概要.md) ー 架空クライアントの設定・目的・ターゲット
2. [docs/02_構成案.md](docs/02_構成案.md) ー サイトマップ・セクション構成・CTA配置・置き換えマッピング表
3. [docs/03_原稿.md](docs/03_原稿.md) ー 各セクションの見出し・本文・ボタン文言
4. [docs/04_デザイン指示文.md](docs/04_デザイン指示文.md) ー 実装用に統合した指示文

## 画像について
写真はすべて生成した架空のイメージ画像です（実在の事務所・人物の写真は使用していません）。

配信サイズを抑えるため、**用途ごとに表示サイズまで縮小したうえでWebPに変換**しています（合計 4.66MB → 1.06MB／77%削減）。

| 用途 | 幅 | 画質 |
|---|---|---|
| 全幅バナー | 1400px | 72（暗いオーバーレイが乗るため低めでも劣化が見えない） |
| 3列カード | 700px | 80 |
| 2列（選ばれる理由） | 1000px | 78 |
| 事務所外観 | 800px | 78 |
| 丸アバター | 400px | 82 |

## 意図的にダミーのままにしている箇所
練習用の架空サイトのため、次の箇所は実装せずプレースホルダーにしています。

- **電話番号**：`000-0000-0000` のダミー。実在しない番号への発信を防ぐため `tel:` リンクにしていません（実案件では必須）
- **アクセスの地図**（`about.html` の `.access-map`）：住所が架空のため地図を埋め込めず、「MAP」のラベルのみ
- **お問い合わせフォーム**：静的サイトのため送信処理はありません（`onsubmit="return false"` で停止）
