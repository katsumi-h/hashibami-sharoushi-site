# 案件概要_はしばみ社会保険労務士事務所（架空・練習用）

※本ドキュメントは実在のクライアントは存在せず、練習のために作成した架空の設定です。

## なぜHPを作ろうと思ったのか（背景と目的）
- これまで紹介中心で仕事を受けており、自社サイトを持っていなかった
- 「法人顧問」と「個人のご相談（年金・障害年金）」の両方を扱っているが、その両方が伝わる場所がなかった
- 名刺代わり・信頼獲得のためのサイトが欲しい

## 事務所のこと
- 事務所名：はしばみ社会保険労務士事務所（架空）
- 開設：2019年
- 所在地：架空（〒000-0000　◯◯県◯◯市◯◯1-2-3）
- 代表：架空の人物（プロフィールはダミー）
- 連絡先：TEL 000-0000-0000（ダミー・tel:リンクは無効化）
- 強み：法人の労務顧問と、個人の年金相談の両方に対応できる「総合型」であること

## サービス内容
**法人のお客様へ**
- 顧問契約・労務相談
- 就業規則の整備
- 給与計算・入退社手続き代行

**個人のお客様へ**
- 年金のご相談
- 障害年金の申請サポート
- 退職後の手続きサポート

## ターゲット
- 法人側：初めて社労士に相談する中小企業の経営者・総務担当者。何を相談していいか分からない段階の人
- 個人側：年金や障害年金の手続きで困っている人。専門用語が分からず不安な人

## このサイトで一番してほしい行動
- 法人・個人それぞれの入口から、無料相談の問い合わせをしてもらう

## サイトの印象
- 誠実
- 親しみやすい（怖くない・相談しやすい）
- 法人と個人、どちらの立場で来ても迷わない

## 優先順位
1. 法人／個人、自分がどちらに該当するかすぐ分かる導線を作る
2. 何をしてくれる事務所か一目で伝える
3. 信頼感を出す
4. 情報を詰め込みすぎず見やすくする
