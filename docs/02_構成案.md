# 構成案_はしばみ社会保険労務士事務所

参考：sanjo-law.com（ひめさゆり法律事務所）の構成をオマージュ。色・写真・コピーはすべてオリジナル。

## サイトマップ（2026-08-21 改訂：お知らせ一覧・依頼までの流れを追加し10ページ構成に）
sanjo-law.comの実サイト構造（グローバルナビ5項目＋その他は別動線）をそのまま踏襲し、10ページすべてを実装。

追加した2ページの意図：
- `news.html`（お知らせ一覧）… トップの「一覧はこちら →」が同じページに戻るだけの**行き止まり導線**になっていたため新設
- `flow.html`（依頼までの流れ）… 士業サイトでは「相談してから依頼までどう進むか」が最大の不安要素。オマージュ元の`/flow/`にならい5ステップで新設

```
index.html（トップ）
├─ corporate.html（法人のお客様へ）
│   ├─ このようなお悩みの方はぜひご相談を（悩み5個）
│   ├─ 導入文
│   └─ 重点分野（労務管理／手続き代行／助成金・補助金）
├─ personal.html（個人のお客様へ）
│   ├─ このようなお悩みの方は是非ご相談を（悩み4個）
│   ├─ 導入文
│   └─ 重点分野（年金相談／障害年金／退職後の手続き／労働トラブル相談／その他）
├─ staff.html（社労士紹介）
│   ├─ プロフィール（写真・所属・出身地・趣味）
│   ├─ 自己紹介文
│   └─ 経歴（年表）
├─ about.html（事務所紹介）
│   ├─ Concept（名前の由来・想い）
│   ├─ 差別化ポイント（3つ）
│   ├─ 事業所情報（正式な表）
│   └─ アクセス
├─ pricing.html（料金について）
│   ├─ 社労士費用の種類（6種類の定義表）
│   ├─ 労務相談料・顧問契約料
│   ├─ 顧問契約プラン（3プラン比較）
│   ├─ 手続き代行の料金
│   ├─ 障害年金申請サポートの着手金・報酬金
│   └─ 助成金申請サポート
├─ question.html（よくあるご質問／ナビには含めずフッターバナー・サイトマップから遷移）
│   ├─ カテゴリ別ジャンプボタン3つ
│   ├─ 法人・個人事業主のお客様からのご質問（6問）
│   ├─ 個人のお客様からのご質問（6問）
│   └─ 全般的なご質問（6問）
└─ contact.html（お問い合わせ／ナビには含めずCTAボタンから遷移）
    ├─ トピック別ボタン3つ
    └─ お問い合わせフォーム
```

グローバルナビ（5項目）：法人のお客様へ／個人のお客様へ／社労士紹介／事務所紹介／料金について
※お問い合わせはナビに含めず、ヘッダーCTAボタン「お問い合わせ・ご相談」からcontact.htmlへ遷移（sanjo-law.comの実際の構造と同じ）
※よくあるご質問もナビに含めず、フッター上部のバナーボタンとフッターのSitemapから遷移（同上）

## フッター構成（2026-08-21 改訂：sanjo-law.comのフッター構造に準拠）
従来の独立したCTA帯（住所＋見出し＋電話＋ボタン）を廃止し、その内容をフッター内に統合。

```
フッター上部バナー（淡ブルー帯）
└─ 写真付きバナーボタン3つ：事務所紹介／料金について／よくあるご質問

フッター本体（濃紺）
├─ 左：ロゴ／住所／リード文／電話番号＋受付時間／お問い合わせCTAボタン
├─ 右：Sitemap（8リンク＝ナビ5項目＋よくあるご質問／お問い合わせ／お知らせ）
└─ 下：練習用サイトである旨の注記／コピーライト
```

参考：sanjo-law.com全6ページ（トップ／法人／個人／弁護士紹介／事務所紹介／費用について／お問い合わせ）の構成をブラウザで直接調査し、忠実に再現。sr-bb.jp「BBについて」（事業所情報表の形式）も一部参照。

## トップページ（index.html）セクション構成

| # | セクション | 目的・ねらい | 主な要素 |
|---|---|---|---|
| 1 | ヘッダー | 迷わせない・すぐ連絡できる | ロゴ／TEL＋受付時間／CTAボタン／ナビ5項目（法人／個人／**事務所紹介**／料金／お問い合わせ） |
| 2 | FV（ファーストビュー） | 3秒で「誰のための事務所か」を伝える | 縦書きキャッチコピー／全幅ビジュアル |
| 3 | Concept | 事務所の考え方・想いで安心感を出す | 英字見出し＋本文3行＋「事務所紹介を見る」リンク→about.html |
| 4 | Service（法人／個人タブ） | **自分がどちらに該当するか**すぐ選べる | タブ切替→各3カード→「一覧を見る」 |
| 5 | 社労士紹介 | 誰が対応するのか顔が見える安心感 | キャッチコピー＋「事務所紹介を見る」リンク→about.html |
| 6 | News・お知らせ | 動いている事務所であることを示す | 日付＋タイトル4件＋一覧リンク |
| 7 | フッターCTA帯 | 最後の後押し | 住所／一言メッセージ／TEL／CTAボタン |
| 8 | フッター（Sitemap） | 全体ナビの補完 | サイト内リンク一覧／コピーライト |

## 事務所紹介ページ（about.html）セクション構成

| # | セクション | 目的・ねらい | 主な要素 |
|---|---|---|---|
| 1 | ヘッダー・パンくず | トップと同じヘッダーで一貫性 | 「ホーム＞事務所紹介」 |
| 2 | ページタイトル | ページの主題を明示 | 「About us 事務所紹介」（sanjo-law準拠） |
| 3 | Concept（名前の由来） | 事務所名に込めた想いで記憶に残す・信頼感 | 「はしばみ」の由来ストーリー＋理念 |
| 4 | 差別化ポイント（Point 01〜03） | なぜここに頼むのかを納得してもらう | 法人・個人の両対応／わかりやすい説明／丁寧な伴走 |
| 5 | 事業所情報（正式な表） | 実在感・信頼感（sr-bb.jp準拠） | 事務所名称／代表者／設立／電話番号／営業時間／所属団体／所在地 |
| 6 | アクセス | 来所前の不安を解消 | 住所・地図（プレースホルダー）・行き方 |
| 7 | フッターCTA帯 | 最後の後押し | トップと共通 |
