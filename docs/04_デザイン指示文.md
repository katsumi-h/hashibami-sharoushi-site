## 付録：sanjo-law.com 全ページ調査ログ（2026-08-16）

トップページだけでなく、実際にブラウザで全6ページを開いて構成を確認した記録。今後別サイトを作る際の「競合リサーチのやり方」の型として残す。

**グローバルナビ（5項目、お問い合わせはナビに含まれない）**
法人のお客様へ／個人のお客様へ／弁護士紹介／事務所紹介／費用について
→ お問い合わせはヘッダー右上のCTAボタンと電話番号のみで到達する動線。ナビをシンプルに保つための工夫。

**/corporate/（法人のお客様）**
eyebrow＋h1 → 「このようなお悩みの方はぜひご相談を」（悩み5個の箇条書き）→ 導入文2段落 → 「重点分野」3カテゴリ×サブ項目リスト → 締めの一文

**/individual/（個人のお客様）**
同じ骨格。悩み4個、重点分野5カテゴリ

**/lawyer/（弁護士紹介）**
弁護士3名分、各人：写真／氏名（漢字＋ローマ字）／所属／出身地／趣味／自己紹介文2段落／経歴（年表）／著書リスト／講演実績。かなり作り込まれた個人ページ

**/about/（事務所紹介）**
Concept（名前の由来）＋Point01〜05（差別化ポイント）＋アクセス（住所・行き方）

**/fee/（費用について）**
「費用の種類」を用語集として表で先に定義 → 業務別の料金表を複数（相談料・顧問料／経済的利益に応じた料率表／分野別の目安）→ 日当表。**「先に用語を定義してから金額を見せる」構成が特徴的**で、専門的な料金体系でも迷わせない工夫になっている

**/contact/（お問い合わせ）**
写真背景の page-title バナー → パンくず（※他ページと違い、パンくずがバナーの下に来る）→ リード文 → トピック別の入り口ボタン（お問い合わせ全般／相続に関する／離婚に関する、の3種）→ LINE公式アカウントの案内

### 学び（次に活かすポイント）
- サブページの悩みリスト・重点分野リストは、**「症状→カテゴリ別の対応」**という流れがどの業種でも応用できる型
- 料金ページは「用語定義→具体的な金額」の順にすると、専門用語だらけでも迷わない
- お問い合わせの入り口をトピック別に分けると、同じフォームでも「自分ごと」として感じてもらいやすい
- 個人プロフィールページ（弁護士紹介）は経歴・著書・講演まで作り込むと信頼感が出る一方、架空サイトで真似る場合は実在の大学名・企業名・著書名を捏造しないよう注意が必要（今回のstaff.htmlでは経歴を一般的な表現に留めた）
